# Near-infrared
近红外测湿度代码 

版本介绍：  大体还是  测量光亮  旋转一圈采集    参考光亮   旋转一圈采集
           采集逻辑 
           主控
           通过GPIO1给高速采集板一个脉冲，证明旋转1度已经完成 开始采样
           每旋转1度采集一次，异常数据触发再次采集；

           通过GPIO2 高电平代表 测量光亮； 低电平代表，参考光亮；

           第一组数据是0度对应的光强值   第359组数据是359度对应的光强值


窗口  判断方式  使用角度判断
